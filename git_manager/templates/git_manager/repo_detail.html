        💻 Config SSH locale — Pousser depuis votre machine
        

            Serveur détecté : {{ server_ip }}:{{ ssh_port }}
        

    


    

        💻 Votre machine
        ── git push relay ──▶
        🐳 {{ server_ip }}:{{ ssh_port }}
        ── git push ──▶
        🐙 GitHub/GitLab
    


    
    


        

            

                ① Générer une clé SSH sur votre machine locale
                ▶
            

            

                
ssh-keygen -t ed25519 -C "relay-{{ repo.name }}" \
  -f ~/.ssh/relay_{{ repo.name|lower }} -N ""

# Afficher la clé publique à copier
cat ~/.ssh/relay_{{ repo.name|lower }}.pub

            

        


        

            

                ② Autoriser votre clé locale sur ce relai
                ▶
            

            

                
Collez ici votre clé publique locale (~/.ssh/relay_{{ repo.name|lower }}.pub) pour générer la commande :

                
                
docker exec -it git_manager bash -c \
  "echo 'VOTRE_CLE_PUB' >> /root/.ssh/authorized_keys && \
  chmod 600 /root/.ssh/authorized_keys"

                
            

        


        

            

                ③ Configurer ~/.ssh/config sur votre machine
                ▶
            

            

                
Host relay-{{ repo.name|lower }}
  HostName {{ server_ip }}
  Port {{ ssh_port }}
  User root
  IdentityFile ~/.ssh/relay_{{ repo.name|lower }}
  IdentitiesOnly yes
  StrictHostKeyChecking no

                
            

        


        

            

                ④ Ajouter le relai comme remote Git
                ▶
            

            

                
Dans votre dépôt local :

                
git remote add relay ssh://root@{{ server_ip }}:{{ ssh_port }}{{ repo.path }}

                
            

        


        

            

                ⑤ Pousser vers le relai
                ▶

                {% for remote in remotes %}
                
→ Push vers {{ remote.name }}/{{ remote.branch }} :

                {% endfor %}
                {% else %}

                {% endif %}
                

                    💡 Le relai repoussera automatiquement vers GitHub si un hook pre-push est configuré.

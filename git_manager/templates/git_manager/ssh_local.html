🔌 Test de connexion
① Générer une clé SSH locale

Sur votre machine, pas sur le relai :

ssh-keygen -t ed25519 -C "relay-local" \
  -f ~/.ssh/git_relay -N ""

cat ~/.ssh/git_relay.pub
② Autoriser la clé sur le relai

Collez votre clé publique :

{{ ssh_command }} \
  "echo 'VOTRE_CLE_PUB' >> ~/.ssh/authorized_keys"
③ Config ~/.ssh/config locale
Host git-relay
  HostName {{ server_ip }}
  Port {{ ssh_port }}
  User root
  IdentityFile ~/.ssh/git_relay
  IdentitiesOnly yes
  StrictHostKeyChecking no
④ Connexion rapide (one-liner)
{{ ssh_command }}

Testez la connexion : ssh -p {{ ssh_port }} root@{{ server_ip }} "hostname"
